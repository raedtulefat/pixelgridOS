# Game Design Document

## Overview

A choice driven, card based life simulation game focused on time progression, structured rounds, and emergent narrative shaped by player decisions.

## Core Loop

Each game is played in batches of five rounds:

1. Time Passed
2. Choice
3. Choice
4. Challenge
5. Bonus

After each batch, the game state evolves based on accumulated decisions and outcomes.

## Setup Phase

The first ten rounds define the player character.

* Background
* Personality traits
* Starting resources
* Early relationships

These choices permanently influence future content.

## Card Types

* Choice Cards: Narrative decisions with trade offs
* Challenge Cards: Skill or stat based resolution
* Bonus Cards: Grant powers or modifiers
* Time Cards: Advance age and unlock new events

## Powers

Powers are earned during Bonus rounds.

* Can be stored
* Can be activated later
* Modify probabilities, outcomes, or narrative branches

## Progression

The game progresses through life stages.
Earlier choices influence available options later.
No hard win state, success is defined by the story that emerges.

## Failure and End States

Failure is contextual rather than absolute.
Some outcomes permanently close paths.
The game ends when the character reaches the end of their lifespan.

## Open Questions

* Should powers have limited uses or cooldowns?
* How deterministic should challenges be?
* Are there hidden stats?
